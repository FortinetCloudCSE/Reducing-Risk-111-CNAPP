## Course Overview

The following content is paired with the FortiCNAPP 111 Xperts course and aims to give you hands on exposure to both a cloud environment (via Amazon Web Services) and the FortiCNAPP console interface. Throughout the subsequent labs you will perform the following functions:

* Deploy a standalone application to a cloud environment
* Explore the changes and challenges with modern cyber attacks that merit new tooling/approaches
* Investigate live security issues in real deployed environments using FortiCNAPP

While the content in this course is meant to be accessible to all audiences, out of necessity, some assumptions will be made for time's sake (and there will be much preamble by the instructor which is not captured here). At any point if you have questions (during a live session or while going through these activities solo) please do not hesitate to ask questions -- We are very enthusiastic to help you learn!

## Tools / Access

A few tools will be used throughout this course to grant you safe access to live environments. Accounts for these tools will be handed out as part of the course. If you are doing this asynchronously from a live event, please reach out to either [Adam](mailto:alarson@fortinet.com) or [Gabe](mailto:gobrien@fortinet.com) to gain appropriate credentials:

1. [Qwiklabs](https://fortinet.qwiklabs.com/users/sign_in) - This tool grants you access to a live, completely sandboxed AWS account. The account will have a lifespan of only around 8 hours and will be automatically deleted. It will also have certain privileges turned off in an effort to protect you from any mistakes. 
**When logging into QwikLabs, you will use the full email address you were provided (e.g. student@corpldap.net).**

2. [FortiCNAPP Console](https://gameday.lacework.net/) - You will be granted read-only access to a demo FortiCNAPP account actively monitoring live assets. No admin capabilities or write functionality will be acessible, but will not be necessary for the coursework. 
**When logging into the FortiCNAPP console, you will use ONLY the user ID you were provided (i.e. NOT using the '@corpldap.com' postpend).**
