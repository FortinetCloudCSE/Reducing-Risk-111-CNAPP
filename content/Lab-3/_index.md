## Lab overview
In this lab you will take on the role of a cloud security auditor. You will start by logging into a AWS Cloud account with a read only user. Explore the account sevices looking for security worst pratices. For this lab you will only need to look a single region: us-east-1.

The point of this lab is to understand how hard it is to manully review a cloud accound, even when it is only single region. Imagine having to review all regions of multuple cloud accounts. Also keep in mind that these accounts are constantly changing.  So what you find today will probably be differnt tomorrow.
